# 😋방법 2를 이용한 모델 
강사님이 알려주신 방법

- 방법2 설명
1. CDE, AB 모델을 따로 학습.
2. 검증 데이터를 두 모델에 넣어 각각 **예측 확률(probability)**을 구함.
3. 예측 확률을 하나의 행렬로 병합함.
4. 가장 확률이 높은 클래스를 최종 예측으로 결정함.
5. 예측 결과와 실제 정답을 비교해 평가.

- 이를 위해 A/B만 있는 데이터셋과 C/D/E만 있는 데이터셋으로 나누었음
- 변수선택도 다시 진행하였는데
- A/B는 이진분류이기 때문에 기존의 ANOVA가 아니라 t-test를 이용했고 기존의 ETA제곱을 통해 설명력을 계산함
- ETA^2의 경우 0.1로 기준을 낮추었음. 0.1로 낮춘 이유는 변수들의 이름만 보았을 떄 서로 다중공선성이 높아보였기 때문에 최대한 기준을 낮춘 것
- 크레머V가 0.1 이상인 범주형 변수를 선택함
- CDE는 ETA제곱 0.14이상, 크레머V는 0.1 이상으로 기존과 동일함.
- 각각 나눠서 설명력을 보니 전체적으로 변화가 조금씩 있었음
